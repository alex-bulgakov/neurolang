# NeuroLang (NL)

**NeuroLang** — независимый язык программирования и легковесная среда исполнения (runtime), спроектированный с нуля на **Go** специально для нейросетей, LLM и автономных AI-агентов.

## 🎯 Зачем нужен отдельный язык для нейросетей?

Существующие языки (Python, JavaScript, Rust) создавались для людей. При их генерации нейросетями возникают фундаментальные проблемы:
1. **Синтаксический шум и раздутый контекст:** Ключевые слова (`function`, `return`, `import`, `class`), скобки, точки с запятой и длинные идентификаторы сжигают драгоценные токены контекстного окна.
2. **Низкая плотность смысла:** Чтобы выполнить простую фильтрацию и маппинг данных, модель пишет 8–15 строк бойлерплейта с циклами и промежуточными списками.
3. **Галлюцинации API:** Из-за многословности библиотек агенты часто ошибаются в сигнатурах методов.

**NeuroLang решает это через парадигму Dataflow + Combinators:**
* **Экономия токенов 50–70%** на алгоритмической логике.
* **Потоковая обработка первого класса (`|`)**: программы строятся как конвейеры трансформации данных.
* **Нативная поддержка инструментов (MCP/Agent-native)** через оператор `!tool.name(...)`.
* **Автономность**: написан на чистом Go, компилируется в единый бинарник `neurolang.exe` без внешних зависимостей.

## ⚡ Синтаксис и Комбинаторы

| Оператор | Название | Описание | Пример | Эквивалент в Python |
|---|---|---|---|---|
| `\|` | **Pipe** | Передача данных по конвейеру | `x \| f` | `f(x)` |
| `?` | **Filter** | Фильтрация элементов потока | `users \| ?(.age >= 18)` | `[u for u in users if u['age'] >= 18]` |
| `@` | **Map** | Проекция / трансформация | `items \| @.name` | `[i['name'] for i in items]` |
| `&` | **Reduce** | Свертка / агрегация | `nums \| &((a, b) -> a + b)` | `functools.reduce(...)` |
| `.` | **Context Dot** | Текущий элемент потока / свойство | `.status == "active"` | `item['status'] == "active"` |
| `!` | **Effect / Tool** | Вызов внешнего инструмента / MCP | `!http.get(url)` | `requests.get(url).json()` |
| `->` | **Arrow** | Лямбда / стрелочная функция | `x -> x * 2` | `lambda x: x * 2` |
| `match` | **Match** | Сопоставление с образцом | `match x { 0 -> "zero", _ -> "any" }` | `match / if-elif` |

### Сравнение на типовой задаче агента:
> *Задача: отфильтровать активные заказы, применить налог 20% и оставить заказы с суммой > 100.*

* **Python (многословно, ~60 токенов):**
  ```python
  def process_orders(orders):
      result = []
      for order in orders:
          if order.get("status") == "active":
              total = order.get("amount", 0) * 1.2
              if total > 100:
                  result.append({"id": order.get("id"), "total": total})
      return result
  ```

* **NeuroLang (ультракомпактно, ~20 токенов — экономия 66%):**
  ```nl
  orders | ?(.status == "active") | @{id: .id, total: .amount * 1.2} | ?(.total > 100)
  ```

## 🛠️ Встроенные Инструменты (Agent Tools)

NeuroLang из коробки предоставляет безопасный интерфейс вызова внешних эффектов и инструментов через оператор `!`:

* `!http.get(url)` — HTTP GET с автоматическим парсингом JSON.
* `!http.post(url, body)` — отправка данных во внешние сервисы.
* `!fs.list(path)` — просмотр директорий.
* `!fs.read(path)` — чтение файлов (с автодекодированием JSON).
* `!fs.write(path, data)` — запись файлов или сохранение состояния агента.
* `!env.get(name)` — доступ к переменным окружения.
* `!time.now()` — текущий таймстемп.

Инструменты могут напрямую участвовать в пайплайнах:
```nl
"logs" | !fs.list | ?(. != "archive") | @("logs/" + .)
```

## 🚀 Быстрый Старт

### Сборка
```bash
go build -o neurolang.exe ./cmd/neurolang
```

### Команды CLI
```bash
# 1. Запуск скрипта
./neurolang run examples/01_basics.nl

# 2. Вычисление однострочника в терминале
./neurolang eval "[1, 2, 3, 4, 5] | ?(. > 2) | @(. * 10)"

# 3. Интерактивный REPL
./neurolang repl

# 4. Анализ расхода токенов BPE и сравнение с Python
./neurolang stats examples/04_token_comparison.nl examples/04_comparison.py
```

## 📂 Структура Проекта
```
neurolang/
├── cmd/
│   └── neurolang/main.go      # Точка входа CLI (run, eval, repl, stats)
├── pkg/
│   ├── ast/                   # Синтаксическое дерево (AST)
│   ├── evaluator/             # Tree-walking интерпретатор и встроенные функции
│   ├── lexer/                 # Токенизатор
│   ├── object/                # Система рантайм-типов (Int, Float, List, Map, Fn...)
│   ├── parser/                # Pratt-парсер с поддержкой пайплайнов и комбинаторов
│   ├── token/                 # Определения токенов
│   ├── tokenmetrics/          # BPE-счётчик токенов и метрики экономии контекста
│   └── tools/                 # Реестр внешних инструментов и эффектов (MCP/HTTP/FS)
├── examples/                  # Примеры программ
└── README.md
```
